# cc1101-probe

Диагностический скетч: проверка работы модулей CC1101 по SPI без внешних библиотек (только штатная `SPI`). Прошивается на обе Arduino Nano, каждая отчитывается по UART (9600 8N1) раз в такт после сброса.

## Обвязка (одинаковая на обеих платах)

| Arduino Nano | CC1101       |
|--------------|--------------|
| 10 (SS)      | CSN (pin 4)  |
| 11 (MOSI)    | MOSI (pin 6) |
| 12 (MISO)    | MISO (pin 7) |
| 13 (SCK)     | SCK (pin 5)  |
| 3.3V         | VCC (pin 2)  |
| GND          | GND (pin 1)  |
| 2            | GDO0 (pin 3) |

## Что делает код (текущая версия)

1. `SRES` - программный сброс чипа: один байт-команда `0x30` (command strobe: R/W=0, B=0), после этого чип в IDLE, все конфиг-регистра в значениях по умолчанию.
2. Читает несколько конфиг-регистров и сверяет их с reset-значениями из даташита (справка, что SPI работает).
3. Читает статус-регистры `PARTNUM` (0x30), `VERSION` (0x31), `MARCSTATE` (0x35) и печатает verdict.

Ключевые моменты SPI-протокола CC1101:

- Байт-заголовок: `R/W` (bit 7) + `B` (bit 6) + 6-битный адрес A5-A0.  Адресное пространство - `0x00-0x3F`; чтение адреса `0x41` отображается в `0x01` и т.д.
- Чтение всегда двухфазное: пока MCU шлёт заголовок, чип отдаёт на MISO статусный байт, а на следующем байте приходит данные регистра.
- Диапазон `0x30-0x3D` двойной:
  - **B=0** - command strobes (запись одного байта: `0x30` SRES, `0x31` STX, `0x34` SRX, `0x32` SIDLE, ...);
  - **B=1** - статус-регистры (только чтение): заголовки чтения `0xF0` (PARTNUM), `0xF1` (VERSION), ..., `0xFD`.
- Конфиг-регистра `0x00-0x2E` читаются заголовком `0x80|адрес` (B=0, R/W=1), запись - `0x40|адрес` (burst) или `0x00|адрес` (single).
