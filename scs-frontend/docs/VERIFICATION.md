# Проверка системы

## Выполнено

- `make test`: 59 автоматических тестов.
- Протокол: SEQ, порядок, uint32, BEAT, все ошибки, BO, неполные/повреждённые
  группы, переполнение, восстановление; SEQ modulo 256 и сохранение диагностики.
- Анализ: строгие границы T/H, равенство, независимые тайм-ауты, повторная
  инициализация состояния, неизвестные/неучитываемые каналы, неоднозначные режимы,
  перенос состояния из истории, статистика и медианы на вручную рассчитанных данных.
- Хранение/API: открытие существующей БД, неизменность исходных данных при
  пересчёте, сохранение настроек, проверки диапазонов/форматов/NaN/Infinity,
  локальная привязка по умолчанию, статические файлы.
- Интеграция serial через отдельные PTY: фрагментация строк, работа без браузера,
  отключение и повторное подключение, ошибки кодировки и чрезмерно длинные строки.
- **Реальный приёмник `/dev/ttyUSB0`**: приходят BEAT и группы всех трёх каналов.
  Данные записаны в `data/telemetry.sqlite3`, в том числе при закрытом браузере.
  Сервис перезапущен с той же БД; накопленная история доступна. На момент проверки
  сохранено более 600 реальных измерений. Прошивки и пороги не калибровались.
- Firefox headless через WebDriver: загрузились настройки, текущие данные трёх
  каналов, анализ и три графика Chart.js; сообщений об ошибках интерфейса нет.
  Проверен скриншот `data/interface.png`. Библиотека графиков раздаётся локально.

## Проверка инструкции для Ubuntu

Инструкция `docs/UBUNTU.md` проверена в чистых контейнерах Docker:

- `ubuntu:24.04` с Python 3.12.3;
- `ubuntu:26.04` (Ubuntu 26.04.1 LTS) с Python 3.14.4.

В обоих окружениях:

- системные зависимости установлены через `apt`, проект и тестовые зависимости — в отдельное venv;
- `make test`: все 59 автоматических тестов пройдены;
- `python -m build`: успешно собраны sdist и wheel;
- wheel установлен в новое чистое окружение, сервис запущен из каталога вне исходников;
- `GET /` и `GET /api/settings` вернули HTTP 200, статические файлы интерфейса доступны из wheel.

Работа с реальным serial-приёмником в контейнерах не проверялась.

## Проверка удаления истории

- `tests/test_history.py`: 10 тестов на отдельных временных БД. Проверены удаление всей
  истории и периода, целостность групп, границы `[start, end)`, время событий,
  сохранение настроек, пустые выборки, отсутствие подтверждения, некорректные
  границы и NaN/Infinity, откат при ошибке SQLite, пересчёт состояний, новые записи
  после удаления и открытие БД после перезапуска.
- Firefox headless с отдельным приложением и `collect=False`: отмена не удаляет
  данные; неверный период отклоняется; удаление периода и всей истории обновляет
  текущие данные, графики и события; ошибка HTTP не показывается как успех;
  запоздалый ответ до удаления не возвращает старые значения на экран.
- Проверен скриншот `data/history-interface.png`. Реальная накопленная история
  при проверке удаления не изменялась.
