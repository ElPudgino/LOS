# Контроллер воздушного клапана

Управление воздушным клапаном модели септика с помощью сервопривода в зависимости от состояния поплавка.

Плата: **Arduino Nano (ATmega328P)**.

## Принцип работы

Поплавок представляет собой обычный ключ, который замыкает или размыкает входной пин на землю. На пине включена внутренняя подтяжка к единице (`INPUT_PULLUP`):

- поплавок разомкнут: пин `HIGH`, заслонка в положении A (45 градусов);
- поплавок замкнут на землю: пин `LOW`, заслонка в положении B (135 градусов).

Чтобы избежать ложных срабатываний, клапан переключается только тогда, когда состояние поплавка стабильно в течение 1 секунды. Перемещение сервопривода выполняется с плавным разгоном и торможением.

## Подключение

| Пин | Назначение |
|-----|------------|
| D5  | Сервопривод: управляющий сигнал |
| A3 (D17) | Поплавок (заземляется ключом, внутренняя подтяжка) |

Поплавок подключается одним проводом к выводу A3 (D17), вторым - к GND. Замыкание ключа переводит вход в LOW.

## Настройки

Все параметры задаются константами в начале `air_valve_arduino/air_valve_arduino.ino`:

| Константа       | Значение | Описание                                                   |
|-----------------|----------|------------------------------------------------------------|
| `SERVO_CTRL`    | 5        | Пин управляющего сигнала серво                             |
| `FLOATER_STATE` | 17       | Пин входа поплавка                                         |
| `SERVO_CENTER`  | 90       | Центральное положение серво (в градусах)                   |
| `SERVO_OFFSET`  | 45       | Отклонение от центра (в градусах)                          |
| `VALVE_POS_A`   | 45       | Положение заслонки: поплавок разомкнут (= CENTER - OFFSET) |
| `VALVE_POS_B`   | 135      | Положение заслонки: поплавок замкнут (= CENTER + OFFSET)   |
| `DEBOUNCE_MS`   | 5000     | Время стабильности состояния перед переключением, мс       |
| `SERVO_MOVE_MS` | 800      | Длительность перемещения между крайними позициями, мс      |

Такое большое значение `DEBOUNCE_MS` выбрано длля того, чтобы сымитировать гистерезис на бесгистерезисном поплавке. Если поплавок сам обладает гистерезисом (как поплавковый переключатель для насосов), то лучше поставить значение 1000мс.

## Сборка и прошивка

Через Makefile (см. `Makefile`):

```sh
make                 # собрать
make flash           # собрать и прошить (порт по умолчанию /dev/ttyUSB0)
make flash PORT=/dev/ttyUSB1
make clean           # удалить артефакты сборки
```

Или напрямую `arduino-cli`:

```sh
arduino-cli compile --fqbn arduino:avr:nano --build-path ./.build air_valve_arduino
arduino-cli upload  --fqbn arduino:avr:nano --build-path ./.build air_valve_arduino --port /dev/ttyUSBx
```
