# 3D-модели узлов системы и стенда

Механические модели для прототипов системы мониторинга и испытательного стенда: воздушный клапан, крепления труб и поплавка, корпуса датчика, передатчика и блока питания, а также элементы привода сервомотора.

- `src/` — редактируемые исходники FreeCAD, SolveSpace, OpenSCAD и Blender.
- `stl/` — экспортированные модели STL и 3MF для подготовки к 3D-печати.

В корне также находятся G-code корпуса передатчика и видеозаписи работы воздушного клапана. Для изменения конструкции следует редактировать файлы из `src/`, а затем обновлять экспортированные модели.
