# CH32V003 Arduino SWIO interface (Arduino Nano)

Простая реализация отладочного интерфейса SWIO для микроконтроллера
CH32V003 на базе **Arduino Nano (ATmega328P, 16 МГц)**.

Перевод прошивки из авроры `arduino-ch32v003-swio` (avr-gcc) на Arduino SDK
(arduino-cli, скетч `swio_nano`).

## Подключение

* `D8 (PB0)` -> пин SWIO чипа CH32V003.

  Прямое подключение работает, но рекомендуется резистор 1k в
  последовательности: при приёме битов намеренно создаётся конфликт
  шины (контроллер тянет линию вниз).

* `D9 (PB1)` -> управление питанием цели.

  Без внешних устройств потребление чипа достаточно мало, чтобы
  удерживать его простым GPIO.

## Протокол

Протокол передаётся по UART 115200 8N1.

Стандартный бутлоадер Nano умеет сбрасывать AVR по линии DTR -
её можно использовать для повторной инициализации адаптера.

При готовности адаптер отправляет символ `!`.

Большинство команд подтверждают выполнение символом `+`.

Аргументы (если нужны) передаются байтами после командного байта.

Поддерживаемые команды:

* `?` - тест UART-связи.
  * Аргументы: нет
  * Ответ: `+`

* `p` - питание цели вкл.
  * Аргументы: нет
  * Ответ: `+`

* `P` - питание цели выкл.
  * Аргументы: нет
  * Ответ: `+`

* `w` - запись debug-регистра цели.
  * Аргументы:
    * `1 байт` - номер регистра (`0x00` ... `0x7f`)
    * `4 байта` - значение (32-bit int, LSB-first)
  * Ответ: `+`

* `r` - чтение debug-регистра цели.
  * Аргументы:
    * `1 байт` - номер регистра (`0x00` ... `0x7f`)
  * Ответ:
    * `4 байта` - содержимое регистра (LSB-first)

## Сборка и прошивка

Через Makefile:

```sh
make                 # собрать
make flash           # собрать и прошить (порт по умолчанию /dev/ttyUSB0)
make flash PORT=/dev/ttyUSB1
make monitor         # читать вывод Serial
make clean           # удалить артефакты сборки
```

Или напрямую `arduino-cli`:

```sh
arduino-cli compile --fqbn arduino:avr:nano --build-path ./.build swio_nano
arduino-cli upload --fqbn arduino:avr:nano --build-path ./.build swio_nano --port /dev/ttyUSBx
```


### Старый бутлоадер (cpu=atmega328old)

На некоторых Arduino Nano (чаще всего китайского производства)
установлен старый вариант бутлоадера ATmega328P. Для таких плат
прошивка с обычным FQBN не проходит, нужно добавить опцию
`cpu=atmega328old`:

```sh
make flash FQBN=arduino:avr:nano:cpu=atmega328old
```
