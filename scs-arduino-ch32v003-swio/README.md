# Адаптеры UART–SWIO для CH32V003

Прошивки самодельного адаптера на ATmega328P для доступа к отладочным регистрам CH32V003. Совместно с minichlink и протоколом Ardulink адаптер позволяет прошивать и отлаживать микроконтроллер, а также управлять питанием цели.

В репозитории два варианта:

- [arduino-ch32v003-swio-nano](arduino-ch32v003-swio-nano/) — версия для Arduino Nano на ATmega328P, 16 МГц.
- [arduino-ch32v003-swio-cross](arduino-ch32v003-swio-cross/) — версия для Arduino Uno R3 или Nano на ATmega328P, 16 МГц; требует проверки на реальном оборудовании.

В обоих вариантах используются UART 115200, линия D8 для SWIO и D9 для управления питанием цели. Подключение, сборка и команды описаны в README соответствующего варианта.
