# Печатная плата приёмника телеметрии

Плата домашнего приёмника системы мониторинга на Arduino Nano и радиомодуле CC1101. Четырёхканальный согласователь уровней обеспечивает подключение 5-вольтовой Arduino к радиомодулю с питанием 3,3 В.

Проект выполнен в KiCad и предназначен для работы с прошивкой [scs-receiver-fw-v1](../scs-receiver-fw-v1/).

- [scs-receiver-pcb-v1.pdf](scs-receiver-pcb-v1.pdf) — принципиальная схема в PDF.
- `scs-receiver-pcb-v1.kicad_sch` и `scs-receiver-pcb-v1.kicad_pcb` — схема и топология платы.
- `gerber/` — Gerber-файлы и сверловка для изготовления.
- `cnc/` — конфигурация и файлы для фрезеровки платы.
