## Дополнительные датчики
https://los-servis.ru/81-wi-fi-gsm-datchiki-dlya-septika
https://gseptik.ru/gs-bio

1. В продаже есть система мониторинга с датчиком мутности. Примеряется обычный дещевый датчик мутности из посудомоечных машин. Такой можно тоже поставить. Обычно их ставят в аэрационную камеру, но дополнительно можно (и даже нужно) поставить на выход септика, чтобы контролировать заиленность стока.

2. Датчик температуры. Скорее информационный датчик, чем диагностический.

3. Датчик уровня. Если только в качестве дублирующего штатный датчик, чтобы все показатели были в одном месте. Можно поставить УЗ-датчик для измерения уровня, а не только для фиксации превышения.
