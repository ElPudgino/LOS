# Документация проекта SCS

Проектная документация системы мониторинга аэрационной станции биологической очистки сточных вод. Цель проекта — создать прототип, который контролирует поток воды в эрлифтах и давление в воздухных магистралях, передаёт данные из станции в дом и помогает обнаруживать неисправности до аварийного переполнения.

Основные материалы:

- [project.md](project.md) — цели, функциональные требования, описание системы и обзор аналогов.
- [project.typ](project.typ) — исходник основного документа на Typst.
- [project.pdf](project.pdf) — готовая PDF-версия.
- `docs/` — краткое описание, рабочие заметки и исследования аналогов.
- `drawings/` и `images/` — схемы и иллюстрации.
- `links.bib` — библиографические источники.
