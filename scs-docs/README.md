# Справочная документация

Сборник технических материалов, используемых при разработке системы мониторинга аэрационной ЛОС: документация на микроконтроллеры, радиомодули, датчики, компоненты питания и сервоприводы, а также распиновки и схемы подключения.

В каталоге находятся материалы по CH32V003, CC1101, N76E003, XKC-Y25-V, MG995, ТП-1201, BH502 и GBJ1510, распиновки Arduino Nano и CC1101 и изображение согласователя логических уровней.

Это справочный архив, а не описание отдельного устройства. Назначение компонентов и особенности их применения приведены в README соответствующих репозиториев проекта.
