# Печатная плата передатчика телеметрии

Плата измерительного блока системы мониторинга на Arduino Nano и радиомодуле CC1101. Предусмотрены согласование логических уровней, подключение трёх датчиков, транзисторные цепи запросов и объединение их линий UART TX.

Проект выполнен в KiCad и предназначен для работы с прошивкой [scs-transmitter-fw-v1](../scs-transmitter-fw-v1/).

- [scs-transmiter-pcb-v1.pdf](scs-transmiter-pcb-v1.pdf) — принципиальная схема в PDF.
- `scs-transmiter-pcb-v1.kicad_sch` и `scs-transmiter-pcb-v1.kicad_pcb` — схема и топология платы.
- `gerber/` — Gerber-файлы и сверловка для изготовления.
- `cnc/` — конфигурация и файлы для фрезеровки платы.
